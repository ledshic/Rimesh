# Rimesh Documentation

Welcome to the Rimesh documentation. Rimesh is a lightweight P2P virtual LAN tool designed specifically for Rimworld multiplayer sessions.

## Overview

Rimesh creates a virtual local area network between players so they can connect to each other's Rimworld servers as if they were on the same home network — without port forwarding or centralized relay servers.

### Key Features

- **Peer-to-peer** – direct connections between players; no central relay
- **Auto-discovery** – LAN broadcast discovers other Rimesh nodes automatically
- **Virtual IPs** – each node gets a stable `10.88.x.x` address
- **Cross-platform** – macOS Apple Silicon and Windows 11+
- **Native desktop app** – Tauri-based app with a Svelte UI
